# 市場暴跌後判斷反轉的5個實用信號

**來源**：@labspeculation X 貼文 (2026/9/19)

市場暴跌後，判斷何時重新買入非常困難。買太早可能還有下跌，等所有人確認反轉，市場已從低點上漲許多。

5個實用信號：
1. RSI底背離
2. 50個月均線
3. 跟進日 (Follow-Through Day)
4. 月線反轉
5. 周線10EMA與20EMA金叉

## 1. RSI底背離
RSI衡量上漲下跌動能。價格新低但RSI未新低，表示賣壓減弱。建議觀察周線RSI，避免短期噪音。

## 2. 50個月均線
代表過去4年平均價格。市場深跌至此線附近時，為歷史極端區域，值得觀察。

## 3. 跟進日
威廉·歐奈爾CAN SLIM體系信號。反彈後第4-7天，主要指數放量上漲1.5%以上，確認買盤回歸。

**注意**：這些信號需結合使用，非單一絕對指標。熊市中可能有假信號。
